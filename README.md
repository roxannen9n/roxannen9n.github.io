# Roxanne (Thao) Nguyen — personal website

Website: https://roxannen9n.github.io/

## Edit

1. Bấm [Edit website content](https://github.com/roxannen9n/roxannen9n.github.io/edit/main/index.html).
2. Tìm đoạn chữ bằng Ctrl+F và thay phần chữ giữa các thẻ HTML. Ví dụ `<p>Hello</p>` thành `<p>Hi, I'm Roxanne.</p>`.
3. Bấm **Commit changes**, lưu vào `main`.
4. Chờ GitHub Pages cập nhật trong tab **Actions**, rồi refresh website. Thường mất vài phút.

- `index.html`: tên, giới thiệu, học vấn, ba dự án và các link GitHub.
- `style.css`: màu, font và bố cục.
- `assets/Resume.pdf`: upload đè cùng tên để đổi CV.
- `assets/selected_trees.png`: hình kết quả shading.
